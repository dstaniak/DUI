# Project instructions

Read the following files once when starting a new chat in this repository
and follow their instructions throughout the chat:

- [General C# guidelines](Skills/GeneralCSharpSkill.md),
- [Project rules](Skills/ProjectRules.md),

Resolve the paths relative to the directory containing this `AGENTS.md` file.

Do not reread these files for each subsequent prompt in the same chat.
Reread the relevant files when the user requests it or reports that the
instructions have changed. If this file changes, check its references for
newly required files.
Apply the C# rules whenever writing, refactoring, or reviewing C# code.

Before every commit, recheck the Git rules in
Skills/ProjectRules.md. This is an exception to the
read-once instruction.

Validate the complete commit message programmatically.
Every line, including the title and body, must contain
at most 60 characters. Insert actual line breaks.

After context compaction, reread any referenced rules
whose contents are no longer available.
